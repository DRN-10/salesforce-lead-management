# Salesforce Lead Management System

## Overview
This project is a Lead Management System built using Salesforce. It automates lead handling and provides insights using reports and dashboards.

## Features
- Custom Object for Lead Management
- Automated lead assignment using Flow
- Automatic status updates
- Custom Report Type creation
- Reports for lead analysis
- Interactive Dashboard visualization

## Project Workflow
1. Created custom object: Lead Management
2. Added fields (Name, Email, Phone, Status, Source)
3. Built Record-Triggered Flow:
   - Auto assigns owner
   - Updates status to "Contacted"
4. Created Reports:
   - Leads grouped by Status
5. Built Dashboard:
   - Visual lead insights
